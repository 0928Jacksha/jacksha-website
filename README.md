Clean multi-page website foundation focused on structure and navigation.

- Home page (root): `index.html`
- Gallery page (root): `gallery.html`
- Subpages: `pages/`
  - `travel.html`
  - `photography.html`
  - `code/index.html`
  - `work.html` (legacy redirect to Code interface)
  - `code/repositories.html` (legacy redirect)
  - `code/repository.html` (legacy redirect)
  - `code/activity.html` (legacy redirect)
  - `code/sync.html` (legacy redirect)
  - `life.html`
  - `contact.html`
- Assets: `assets/`
  - `css/main.css`
  - `css/work.css`
  - `js/main.js`
  - `js/gallery.js`
  - `js/code-system.js`
  - `images/`
    - `gallery-manifest.json`

## Notes
